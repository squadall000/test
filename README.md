# Surface Unevenness Detection Demo

This repository contains a simple Python script that uses OpenCV to capture
frames from a camera, highlight surface irregularities, and display the
processed image in real time.

## Requirements
- Python 3
- OpenCV (`opencv-python` package)

Install dependencies with:

```bash
pip install opencv-python
```

## Usage
Run the script directly from the repository root:

```bash
python detect_unevenness.py
```

Press `q` in the window that appears to exit the program.
